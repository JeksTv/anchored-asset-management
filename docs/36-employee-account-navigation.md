# Employee account access navigation

Kit Templates and Account Requests are removed from the sidebar. New request creation is removed from the account panel. Existing account records remain available in Employees > employee profile > Accounts & access, including Record existing account, editing account details and recording deactivation. Existing pending request records retain their resolution controls to avoid stranding clearance obligations.

No account, assignment, template or historical record is deleted. Existing onboarding kit records and tasks remain available for traceability and completion.

The Onboarding kit tab is also removed from employee profiles. Historical kit data is retained; provisioned items continue to include any recorded accessories/access.
